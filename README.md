# Global Feed

Лендинг проекта **Global Feed** — социальной сети с хронологической лентой и приватными чатами на сквозном шифровании.

## Стек

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Ванильный JavaScript (IntersectionObserver)

Без сборки и зависимостей — открывается напрямую в браузере.
